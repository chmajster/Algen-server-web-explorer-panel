# WebNAS 0.1.19

- Added context actions to Start → Recently Used applications so recent entries support the same actions as the main application list.
- Improved Module Center responsiveness with progressive catalog rendering and restored the standard install action for compatible uninstalled modules, including Proxmox Manager.
- Added DATA Communication & Segmentation Tool (DCST): canonical APMID/ENV inventory projection, dynamic TAG/IPSet reconciliation, reusable Ports and Services, Proxmox Firewall API integration, drift/dry-run/verification, granular RBAC, audit, utilities, frontend management UI, and regression coverage.
