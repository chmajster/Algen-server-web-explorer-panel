# WebNAS 0.1.20

- Redesigned Resource Monitor into a compact infrastructure dashboard with responsive CPU, memory, storage, network and process views plus reusable bounded-history SVG charts.
- Added local process filtering, sorting and Top 10/25/50/All controls backed by the complete administrator process list from the existing resource endpoint.
- Hardened monitoring refresh and aggregation behavior by preserving non-overlapping polling and last-good data, deduplicating structured alerts, and excluding common virtual links from aggregate network traffic.
