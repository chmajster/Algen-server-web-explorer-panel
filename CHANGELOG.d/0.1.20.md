# WebNAS 0.1.20

- Redesigned Resource Monitor into a compact infrastructure dashboard with responsive CPU, memory, storage, network and process views plus reusable bounded-history SVG charts.
- Added local process filtering, sorting and Top 10/25/50/All controls; the general resource response stays bounded while the monitor requests the complete administrator process list from a dedicated admin-only detail endpoint.
- Hardened monitoring refresh and aggregation behavior by preserving non-overlapping polling and last-good data, deduplicating structured alerts, and classifying bridges and virtual network links from Linux sysfs topology before calculating aggregate traffic.
- Scoped Resource Monitor table styling beneath `.monitor-app` so loading the monitor cannot alter unrelated DNS, routing or other settings tables that reuse generic table wrapper classes.
- Unified displayed and package metadata versions so the backend status API, About view, Python package metadata, frontend package metadata and lockfile all report WebNAS 0.1.20 from canonical sources.
