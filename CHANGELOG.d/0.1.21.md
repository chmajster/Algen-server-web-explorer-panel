# WebNAS 0.1.21

## Fixed

- Nieobsłużone błędy backendu nie kończą się już wyłącznie komunikatem `Internal Server Error`. API zwraca bezpieczny kontrakt diagnostyczny z kodem błędu, etapem, ścieżką endpointu, typem wyjątku, identyfikatorem żądania i wskazówką do odnalezienia tracebacku w logach.
- Proxmox Manager zwraca kontekst operacji również dla nieoczekiwanych błędów konfiguracji, testu połączenia, synchronizacji, inventory i akcji zasilania.
- Klient frontendowy pokazuje dla błędów serwera HTTP status, kod, ID błędu, etap, endpoint, przyczynę, status upstream i sugestię, zamiast redukować odpowiedź do ogólnego tekstu.
- Surowe odpowiedzi HTTP 500 bez strukturalnego payloadu są wyświetlane z informacją, że szczegóły należy sprawdzić w logach backendu.

## Security

- Komunikaty diagnostyczne nie ujawniają hasła, tokenu, treści wyjątku ani query stringu. Pełny traceback pozostaje wyłącznie w logach serwera i jest korelowany przez bezpieczny `request_id`.
