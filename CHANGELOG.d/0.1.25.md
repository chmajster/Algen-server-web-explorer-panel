# WebNAS 0.1.25

## Performance

- Ograniczono I/O File Managera przez `os.scandir()`, paginację przed pełnym pobieraniem metadanych dla sortowania po nazwie/typie oraz ograniczone czasem, liczbą wpisów i wyników wyszukiwanie rekursywne.
- Resource Monitor korzysta ze współdzielonego samplera FAST/MEDIUM/SLOW/STATIC zamiast wykonywać kosztowne pomiary osobno dla każdego klienta; per-user filesystem probes mają bounded cache i single-flight przy równoczesnym cache miss.
- Resource Monitor i Generic Module wykorzystują istniejące zdarzenia runtime SSE, a polling pozostaje wyłącznie jako rzadszy fallback przy utracie realtime; polling tasków i aktualizacji jest ograniczony do stanów, które faktycznie go wymagają.
- Słowniki `pl-PL` i `en-US` są ładowane jako osobne lazy chunks, a gorące endpointy mają lekkie, bezpieczne pomiary czasu wykonania.

## Security

- Dane sterowane przez użytkownika (`user`, `op`, `payload`) nie trafiają już do argv uprzywilejowanego workera plikowego; kompletna zweryfikowana koperta jest przekazywana przez stdin przy zachowaniu istniejących granic UID/GID i polityk ścieżek.

## Testing

- Dodano testy regresyjne i wydajnościowe dla katalogów 1k/10k wpisów, bounded search, współdzielonego samplera, równoległych cache missów, fallbacków realtime oraz transportu privileged workera.
