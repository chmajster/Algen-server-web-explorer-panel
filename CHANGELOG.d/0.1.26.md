# WebNAS 0.1.26

## Performance

- Aggregated authenticated startup profile and update state behind the internal `/api/bootstrap` endpoint, reducing startup request fan-out while preserving the existing API consumers.
- Added one-shot frontend seeding for bounded bootstrap responses and retained `/api/auth/me` as the lightweight CSRF/session resynchronization path.
- Added a small thread-safe TTL cache for the module public catalog with explicit invalidation after health diagnostics change.
- Kept global and per-user transfer history off the bootstrap critical path; transfer lists are loaded only after session restoration.

## Reliability

- Bootstrap failures fall back to the legacy session endpoint without allowing superseded asynchronous requests to overwrite a newer authenticated session.
- Update completion metadata remains outside the bootstrap request so remote release timestamp lookup cannot delay login.

## Testing

- Added regression coverage for bootstrap RBAC/update selection, deferred transfer history, no-store headers, seeded reads, legacy fallback, superseded-session races, TTL reuse and catalog invalidation.
