# WebNAS 0.1.27

## Infrastructure modules

- Added Secrets Manager as the authoritative encrypted WebNAS secret store with controlled module sharing, audit history, encrypted backup/restore, key-rotation planning and a fail-safe Credentials migration that preserves stable credential IDs.
- Added Fail2Ban Manager with jail/service status, ban and unban controls, managed override validation, safe rollback, bounded logs and event publishing.
- Added Webhook Manager with event subscriptions, delivery history, retry/backoff, HMAC signing and authentication backed exclusively by Secrets Manager references.

## Security and compatibility

- Preserved existing Hosts Manager, Ansible, Proxmox, Redfish/IPMI, Git and power-profile credential references through a compatibility adapter and metadata-only legacy FK shadows.
- Hardened webhook delivery against SSRF, DNS rebinding and redirect bypasses by resolving and validating every target before each attempt and connecting only to the validated address while preserving TLS hostname verification.
- Restricted private-network webhook targets to the critical configure permission and exposed only webhook-scoped secret metadata to Webhook Manager users.
- Prevented deletion of secrets referenced by infrastructure or webhooks, securely erased deleted encrypted payloads, released deleted names for reuse and exposed metadata-only usage locations.
- Removed internal exception details from Secrets Manager API errors and stopped advertising webhook event types without wired publishers.

## Interface and testing

- Added Polish/English Secrets Manager, Fail2Ban Manager and Webhook Manager applications, including secret environment filtering/editing and usage-location visibility.
- Added regression coverage for credential migration/rollback, encrypted metadata boundaries, secret deletion/reference safety, Fail2Ban validation and rollback, webhook HMAC/authentication, pinned-address SSRF protection, redirect handling and retry cancellation.
