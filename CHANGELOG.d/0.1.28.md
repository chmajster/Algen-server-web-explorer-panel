# WebNAS 0.1.28

## Proxmox Manager

- Expanded Proxmox Manager with live node, storage, cluster and VM detail views while keeping Host Registry as the single source of truth for VM/LXC identity.
- Added central UPID task tracking, task logs and terminal-state polling for asynchronous Proxmox operations.
- Added snapshots, cloning, validated migration, hardware changes, safe disk growth, template visibility, backup visibility and the Create VM workflow without persisting plaintext secrets.
- Added full per-connection inventory auto-sync with configurable intervals, per-connection locking, error isolation and exponential backoff.
- Split the frontend into focused Overview, Virtual Machines, Nodes, Storage, Cluster, Tasks, Templates and Connections views with dedicated operation dialogs.
- Preserved stable Host Registry identities across migrations and integrated operational state with the existing Activity/Operations infrastructure.
- Added regression coverage for task handling, inventory, migrations, snapshot confirmation, disk growth protection, scheduler locking and error isolation.
- Updated the generated OpenAPI contract and Proxmox Manager documentation after integrating the Secrets Manager-based credential compatibility layer from WebNAS 0.1.27.
