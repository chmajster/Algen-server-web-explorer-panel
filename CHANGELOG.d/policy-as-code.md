## Policy-as-Code Engine

- Added a first-class Policy-as-Code module with YAML and JSON policy storage.
- Added a bounded declarative assertion DSL with validation and deterministic evaluation; policy source never executes Python or shell code.
- Added CRUD, validation, single-policy and all-enabled evaluation APIs with least-privilege RBAC.
- Added a desktop policy editor with source validation, JSON facts input and per-rule evaluation results.
- Added backend and frontend tests plus module documentation.
